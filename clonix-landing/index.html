ANSWERS

Frequently Asked Questions

Does Clonix keep custom page templates like newmedda and newqabz? +
Yes. Unlike generic migration apps that reset templates to product.liquid, Clonix audits active and draft theme templates, creates matching template suffixes on the destination store, and maps each product and page accordingly.
Will my new store still hotlink images to the old store? +
Never. Clonix implements Zero-Leak CDN Ingestion. Every image, video, and file is uploaded via Shopify's Staged Upload API into the destination store's CDN, and all HTML references are rewritten in memory. If the old store is closed tomorrow, your new store remains 100% intact.
Who pays the $9 Single Pass fee? +
Only the Destination Store merchant pays the $9 one-time fee upon claiming the migration run. The source store never incurs any charge.
How long does a pairing token last? +
Each 8-character Crockford token has a strict 15-minute Time-To-Live (TTL). If unclaimed within 15 minutes, the token expires automatically to prevent unauthorized access.
